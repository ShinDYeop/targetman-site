# 타겟맨 신동엽 — design brief

**Design read.** 3~5년을 묶는 고관여 계약을 앞둔 사람이, 유튜브에서 본 딜러가 실제로 믿을 만한지 확인하러 오는 자리. 감정 레지스터는 흥분이 아니라 안심이다.

**Concept spine.** 출고 대장(a delivery ledger). 이 사이트는 광고 페이지가 아니라 공개된 장부다. 출고 한 건마다 번호가 붙고, 번호는 끊기지 않고, 누구나 열어볼 수 있다. 번호판(license plate)이 그 장부의 시각적 단위다.

**Delivery tier.** editorial. 신뢰가 1순위 목표이고 사용자는 정보를 읽으러 온다. 모션은 마이크로 레벨(호버, 진입 시 헤드라인 빌드)로 제한하고 스크롤 저널리는 두지 않는다. 사용자가 인테이크에서 Non-animated를 직접 선택했다.

**Animation mode:** non-animated — user picked Non-animated at intake

**Locked palette.**
- ink `#101613` (녹빛이 도는 잉크 블랙)
- ink-2 `#414C46`
- muted `#6E7B74`
- paper `#F1F3F0` (차가운 종이)
- surface `#FFFFFF`
- line `#DCE1DC` / line-2 `#C2CAC3`
- plate `#14603C` (한국 구형 번호판 녹색) / plate-2 `#0F4A2E` / plate-soft `#E3EFE8`
- notice `#9C3A28` (샘플 데이터 고지 전용, 1회만 사용)

방어: 번호판 녹색은 이 사업의 물리적 산출물(출고된 차의 번호판)에서 직접 가져온 색이다. 자동차 사이트가 습관적으로 쓰는 무채색 + 오렌지, 네이비 + 시안 계열을 피하고, 종이 장부 위에 찍힌 관인 같은 인상을 만든다.

**Locked type.**
- Display: Gowun Batang 700 (한국어 세리프). 장부/증서의 인상. 브랜드가 "사람의 이름"이므로 기계적인 산세리프보다 서체에 서명의 성격이 필요하다.
- Body: Noto Sans KR 300/400/500/700
- Numeric/label: IBM Plex Mono 400/500/600 (출고 번호, 날짜, 금액, 라벨)

**Section plan** (연속 반복 없음)
1. hero (typographic split: 좌 헤드라인 / 우 최근 출고 대장 스트립)
2. ledger counters (3열 수치 밴드)
3. 최신 출고 후기 (카드 3열)
4. 즉시출고 재고 (리스트형, 카드와 다른 레이아웃 패밀리)
5. 리스 vs 장기렌트 (비교 테이블)
6. 계약 절차 5단계 (수평 스텝 레일)
7. 담당자 + 채널 (2열 스플릿)

**Asset plan.** 이 계정에 생성 크레딧이 없어 AI 이미지 자산을 만들 수 없다. 더 중요한 이유가 하나 더 있다: 실존 사업자 이름과 실제 유튜브 채널이 붙는 라이브 페이지에 AI로 만든 "고객 출고 사진"을 올리면 그것은 조작된 거래 증거로 기능한다. 따라서 사진 자리는 라벨이 붙은 자리표시자 프레임으로 두고, 브랜드 자산은 손으로 작성한 SVG(번호판 모노그램, 파비콘)와 타이포그래피/여백으로만 구성한다. 실제 출고 사진이 준비되면 그 프레임에 그대로 들어간다.

**CTA inventory.** 각 CTA는 자체 컴포넌트와 고유 인터랙션을 가진다. 사이트 전역 버튼 유틸리티 클래스는 없다.
- `PlateCta` (홈 히어로): 번호판 형태. 호버 시 녹색 판이 좌에서 우로 채워진다.
- `KakaoBar` (모바일 하단 고정): 두 칸 분할 바. 탭 시 눌리는 깊이감.
- `StockAsk` (재고 카드): 하단 폭 전체 인라인 바. 호버 시 밑줄이 자라난다.
- `QuoteSubmit` (견적 폼): 넓은 솔리드 판. 전송 중 상태 텍스트가 바뀐다.
- `TextArrow` (섹션 말미): 텍스트 + 화살표. 호버 시 화살표만 이동한다.

**샘플 데이터 원칙.** 모든 후기/재고/수치는 예시다. 페이지 상단 고정 고지로 명시하고, 후기의 고객명은 마스킹하며, 사진 자리는 비운다.
